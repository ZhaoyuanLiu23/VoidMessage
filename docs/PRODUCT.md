# 产品与交互说明

## 产品主张

**匿名，也可以认真地说话。**

VOID MESSAGE 希望减少昵称、头像、粉丝数与个人主页对表达的干扰。用户仍然拥有稳定账号，但公开交流只留下颜色这一种轻量特征。

## 信息架构

### 一级：六大兴趣板块

体育、兴趣、科技、艺术、学习、游戏。一级页面强调探索感，采用黑灰背景、暗红扑克牌符号和克制动态光效。

### 二级：36 个细分房间

每个板块包含六个主题。二级页面保留返回按钮和所属板块语义，卡片使用统一图标系统，降低选择成本。

### 三级：匿名聊天室

聊天页参考移动通讯软件的熟悉结构：顶部房间信息、中部时间序消息、底部固定输入区。自己的消息靠右，其他用户靠左；颜色头像是唯一公开身份。

## 核心交互

1. 访问者从登录页使用个人邮箱注册或登录。
2. 系统分配一种颜色，并在右上角蝙蝠侠头像中展示。
3. 用户先选择板块，再选择具体房间。
4. 输入框提示文字随光标与键入位置自然变化。
5. 发送成功后立即合并服务端消息。
6. 页面持续拉取新增消息，并在用户位于底部时自动滚动。
7. 内容溢出后保留历史顺序，不覆盖其他用户消息。

## 视觉语言

| 元素 | 原则 |
| --- | --- |
| 色彩 | 以 #050505、#0f1012、#e7e7e7 为基底，暗红用于强调，用户色仅用于身份 |
| 字体 | 大标题高对比且控制换行；正文使用舒适行高与最大阅读宽度 |
| 图形 | 镂空扑克牌、蝙蝠侠轮廓、细边框和低透明噪点 |
| 动效 | 只服务于层级切换、卡片反馈和重点引导，避免持续干扰阅读 |
| 响应式 | 桌面强调空间和氛围，手机优先保证输入、返回和最新消息可达 |

## 成功指标建议

- 首次访问到进入房间的完成率
- 登录与注册失败率
- 消息发送成功率及 P95 延迟
- 增量同步重复率、漏消息率
- 首日和七日房间回访率
- 举报率及处理时长

指标采集应遵循最小化原则，不建立跨站追踪或公开用户画像。
